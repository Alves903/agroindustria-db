# Agroindústria - Banco de Dados

Projeto desenvolvido na Atividade 8 da disciplina de Banco de Dados do curso Técnico em Desenvolvimento de Sistemas - SENAI.

## Sobre o projeto

O projeto simula um banco de dados para o monitoramento de uma agroindústria de açúcar e etanol.

O banco armazena os setores da indústria e as medições coletadas durante os processos.

## Tabelas

- `setor` - armazena os setores da agroindústria.
- `medidas` - armazena as medições realizadas em cada setor.

## Consultas realizadas

Durante a atividade foram utilizadas consultas com:

- SELECT
- WHERE
- ORDER BY
- COUNT
- AVG
- MIN
- MAX
- GROUP BY
- INNER JOIN

As consultas permitem filtrar e ordenar medições, calcular médias, encontrar valores mínimos e máximos e contar a quantidade de medições por setor.

## Tecnologias utilizadas

- SQL
- SQL Server
- SQL Server Management Studio (SSMS)
